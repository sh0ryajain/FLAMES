# FLAMES 🔥

A small C++ project I made to recreate the classic FLAMES game.

The program takes your name and your crush's name, removes matching characters, and uses the remaining character count to eliminate letters from **FLAMES** until one relationship category is left.

### What is FLAMES?

- **F** – Friends
- **L** – Love
- **A** – Affection
- **M** – Marriage
- **E** – Enemies
- **S** – Siblings

### How to Run

1. Clone the repository.
2. Compile the C++ file using a compiler such as g++.
3. Run the program and enter two names, one per line.

```bash
g++ main.cpp -o flames
```

On Windows:

```bash
flames.exe
```

On Linux:

```bash
./flames
```
